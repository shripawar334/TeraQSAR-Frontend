# TeraQSAR — Frontend

TeraQSAR is a web-based research prototype for exploring AI-based QSAR predictions of grouped historical pregnancy-risk categories using molecular descriptors.

The frontend provides an interactive interface for entering molecular descriptors and viewing predictions generated by a FastAPI backend.

## Features

- Modern, responsive user interface
- Black and emerald green theme
- Molecular descriptor input form
- Prediction category display
- Class probability visualization
- Input validation and error handling
- Research disclaimer and model limitations

## Technology Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## Input Features

The prediction interface accepts five molecular descriptors:

- `a_acc` — Hydrogen-bond acceptors
- `a_don` — Hydrogen-bond donors
- `b_rotN` — Rotatable bonds
- `SlogP` — Molecular lipophilicity descriptor
- `Weight` — Molecular weight in g/mol

## Getting Started

### 1. Clone the repository

```bash
git clone <YOUR_FRONTEND_REPOSITORY_URL>
cd TeraQSAR-Frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure the Backend API

The frontend must connect to the deployed FastAPI backend to generate predictions.

Update the API URL in the prediction page to use the public backend URL instead of the local development address.

For production deployments, consider configuring the API URL through a Next.js environment variable.

### 4. Start the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Main Pages

- **Home:** Project introduction and overview
- **About:** Dataset, descriptors, methodology, and limitations
- **Prediction:** Submit molecular descriptors and view model outputs

## Deployment

The frontend can be deployed on Vercel. Configure the production backend API URL and ensure the backend allows requests from the deployed frontend origin.

## Important Disclaimer

TeraQSAR is an educational and research prototype. Its predictions are based on grouped historical pregnancy-risk categories and are not a clinically validated assessment of teratogenicity, fetal harm, or drug safety.

Model class probabilities are not probabilities of fetal harm. This application must not be used to make medical decisions.
